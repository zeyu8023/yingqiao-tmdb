CONNECTION SETTINGS

把连接交给你的网络。

支持 Clash / OpenClash 的 HTTP 或 mixed 端口，也可以直接连接。

01 上游网络

填写 NAS 能访问的 Clash 地址，留空表示直连。不是 OpenWrt 的管理页面地址。

02 对外访问

公网使用时填写映桥的专用反代域名；留空使用当前浏览器地址。请不要填写 OpenWrt 管理页面的域名。

03 图片缓存

32–4096 MB，图片保存 7 天，达到上限时淘汰较久未访问的图片。资料接口不缓存。

保存后对新请求生效

公网访问怎么接？

  1. 在 NAS 的反向代理中，为映桥新建专用域名。
  2. 将该域名转发到 NAS 的 18012 端口，开启 HTTPS。
  3. 在「连接设置」中填入这个公网根地址并保存。
  4. 重新复制这里的两条地址，在流影中保存。

管理页面仍需密码；加速请求通过链接中的独立密钥访问。请保留 TMDB 应用凭据。
